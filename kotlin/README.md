# ForgeKit for Kotlin

The Kotlin module comes in Phase 3. Until then this directory is a placeholder
so the shared-package layout is visible from the start.

ForgeKit's Swift package is the source of truth for the forge contract: the
models, the `Forge` operations, and the GitHub/gitboy behavior. The Phase 3
Kotlin module will mirror that contract for Android rather than invent a second
one.

Nothing here is built or published yet.
